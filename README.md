# Knight's Tour

A small interactive app that lets you play the classic **Knight’s Tour** puzzle directly in the browser.

The goal is simple: move the knight across the board using standard chess moves, visiting every square exactly once.

---

## How to Play

1. Click any cell to choose the starting position.
2. Move the knight by clicking valid target cells.
3. Each visited cell is marked with the step number.
4. Try to visit all cells exactly once.

---

## Features

* Dynamic board (supports multiple sizes, including rectangular boards)
* Move history tracking
* Undo last move
* Optional hint system (shows valid moves)

---

## Development

This project uses pnpm.

```bash
pnpm install
pnpm dev
```
